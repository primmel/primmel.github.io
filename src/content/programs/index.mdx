# Programs on the platform

One language, one platform — the programs are the ladder's rungs. Each
is a SMART program built on Primmel SMART: the same methodology, the
same engine, never a fork.

## Live today

### [OIML SMART](https://www.oimlsmart.org)

The legal-metrology program (the OIML's own): R 60 (load cells),
R 91 (speed meters), R 129 (dimensioners), R 144 (gas analytical
systems) modeled in Primmel; the OIML-CS certification system (B 18)
executing as data; CNML machine-readable certificates on the Confium
PKI; the simulated SMART twins (SST) of the four instrument families;
the twin-fidelity certification program (TW-1). The program's front
door is [oimlsmart.org](https://www.oimlsmart.org); its NMI audience
page is [the legal-metrology section](https://primmel.github.io/primmel-oiml-smart/nmi/).

## The open slots (〈scope〉 SMART)

The ladder is built for more programs — the platform machinery is
program-shaped by construction (the program config seam, the boundary
gate, the integration manifest). Each slot instantiates with zero
forks:

- **Accreditation services (ISO/IEC 17011 chain)** — the CASCO
  foundation packages already model the 17000-series; an accreditation
  program composes them against its own scheme documents.
- **MSS certification (ISO 9001 and friends)** — management-system
  standards as Primmel models; an auditor reads one integrated
  implementation through the single-standard lens.
- **Laboratory programs (ISO/IEC 17025 chains, ILAC)** — the lab
  competence model is already first-class (the verification pathways
  and the lab implementation packages of the OIML program).

A slot is honestly a slot: named, shaped, never claimed as shipped.

## How a program joins

1. Model the standard in Primmel (the rec package — clause-URN
   provenance throughout).
2. Instantiate the program config (one manifest — branding, roles,
   copy).
3. Register the repos in the integration manifest (the contracts
   that prove the links).
4. The engine does the rest — the same gates, the same workflow, the
   same twin machinery.
