# The Primmel SMART platform

Primmel is the language. **Primmel SMART** is the
platform built on it: the runtime that executes the models, the twin
machinery that watches real instruments against them, and the
certification pattern that proves the twins. Each piece is real,
gated, and documented in its own volume, this page is the map.

## The pieces

| Piece | What it is | Where it lives |
|---|---|---|
| **The methodology** | The model is the source of truth; tooling is a pure engine. Recommendations are modeled once; the whole certification workflow runs from the models. | [the SMART platform runtime](https://primmel.github.io/primmel-smart-docs/platform/) |
| **The app framework** | The server-rendered shell every program's app is an instance of, OIML SMART is instance #1, configured by ONE program manifest (the program config seam). | [the program config](https://primmel.github.io/primmel-smart-docs/platform/07-the-program-config/) |
| **The twin runtime** | Connectors with fail-`unavailable` semantics, freshness-gated cycles over the SAME verdict engine, append-only evidence streams, re-judgment from stored snapshots. | [the runtime overview](https://primmel.github.io/primmel-smart-docs/platform/) |
| **Primmel SST** | The simulated-SMART-twin framework: two channels (`/twin` the governed projection, `/world` the physics), the twin schema generated from the product reference package, a physics core honest enough to certify against. | [the SST page](/sst) |
| **Twin certification** | A twin's projection certified against its fidelity requirements, surveillance, the certificate machine, the composite (the weakest declared link, always printed). | [twin certification](https://primmel.github.io/primmel-smart-docs/primmel/17-twin-certification/) |
| **Confium** | The threshold-cryptography PKI ([confium.org](https://www.confium.org)) the platform's certificates ride, the signing key exists only as shares, so no single party signs alone. Each program names its own certificate format on it (OIML SMART's is CNML). | [the Confium page](/confium) |

## The governed projection, in one diagram

The platform's central idea: a manufacturer's full digital twin (any
shape) is projected through the standard's governed aspect set, the
Primmel twin is only what the standard governs, and the certification
proves the projection, never the full twin.

![The three-layer twin: physical device → full digital twin → the governed Primmel projection → twin certification](/diagrams/shared/three-layer-twin.svg)

## The programs it powers

The platform hosts programs, [OIML SMART](https://www.oimlsmart.org)
today, 〈scope〉 SMART slots tomorrow (accreditation, MSS
certification, lab programs), each instantiating with zero forks.
[The programs page](../../programs/) is the directory.
