# 18 — Improve 404 page UX

## Problem

The 404 page shows a message but no way to recover. Users who hit
a dead link have to manually navigate back.

## Fix

Add to 404 page:
- Search button (Pagefind) — let users search for what they wanted
- Quick links to main sections (Architecture, Examples, Docs)
- "Go home" CTA button
- Report link (GitHub issue)
